# Project 1 workspace

We keep our research record and the hand-in package separate:

- [`Experiments/`](Experiments/README.md) contains the notebooks, exploratory
  token-task code, working reports, figures, references, and presentation.
  The notebooks, presentation file, references, raw runs, and feature data
  stay local and are ignored by Git. It is not the submission package.
- [`submission/`](submission/README.txt) contains the aligned Omniglot code,
  focused tests, dependencies, and run instructions. The contribution
  statement remains local until all members approve it; the extended abstract
  and declarations will be added after the development and results review.
- [`PROJECT_CHECKLIST.md`](PROJECT_CHECKLIST.md) tracks preparation through
  the submission review.

We run package commands from inside the relevant folder. Local virtual
environments, when present, remain at the workspace root and are not part of
either package.

The course brief, paper copy, and older abstract draft in
`Experiments/references/` are local references, not files to publish or submit
as our own work. The official Moodle abstract template is not yet in this
workspace. Our code
uses the published feature data through a checksum-verified download; it does
not redistribute that dataset or the paper authors' source code.
